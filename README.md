## 🚀 Featured Cybersecurity & AI Security Projects

### 1. 🛰️ ThreatTrace — Analyst-Governed AI Security Platform

An AI-assisted security research platform that connects bug-bounty discovery, multi-tool scanning, evidence correlation, threat intelligence, and detection engineering into one bounded workflow — where the AI reasons and proposes, but a deterministic policy layer and a human make every decision.

**Key Areas:** AI Agent Security, Human-in-the-Loop Approvals, Detection Engineering, Bug-Bounty Automation, Security Governance

**Tech Stack:** Python, FastAPI, Docker, MITRE ATT&CK, MITRE ATLAS, Nmap, Nuclei, OWASP ZAP

🔗 **Repository:** [View ThreatTrace](https://github.com/RoshiniMlakshmana/ThreatTrace)

### 2. 🔐 MCP Vulnerability Detection Gateway

An AI security gateway designed to inspect and control communication between **LLM applications, AI agents, MCP clients, and MCP servers**.

The project focuses on detecting unsafe tool calls, malicious prompts, unauthorized actions, sensitive-data exposure, and security risks before requests reach connected MCP tools.

**Key Areas:** MCP Security, AI Agent Security, Prompt Injection Detection, Tool-Call Validation, Access Control, LLM Security

**Tech Stack:** Python, FastAPI, MCP, Langflow, LLM Guardrails, MITRE ATLAS, OWASP LLM Top 10

🔗 **Repository:** [View MCP Vulnerability Detection](https://github.com/RoshiniMlakshmana/MCP-vulnerability-detection)

### 3. 🛡️ LLM- Guardrail

A real-time AI security guardrail that analyzes incoming prompts and outgoing model responses, classifying activity as **Allow, Flag, or Block** based on confidence scores.

Detects prompt injection, jailbreaks, system-prompt theft, API-key phishing, encoded attacks, multilingual attacks, multi-turn attacks, PII leakage, and sensitive-data exposure.

**Key Areas:** LLM Security, Prompt Injection Detection, Guardrails, Red-Team Evaluation, PII Protection

**Tech Stack:** Python, FastAPI, scikit-learn, RoBERTa/DeBERTa, Sentence-Transformers, Chroma, Presidio, Docker, OWASP LLM Top 10, MITRE ATLAS

🔗 **Repository:** [View AI Attack Detection Classifier](https://github.com/RoshiniMlakshmana/LLM-Guardrail)

### 4. 📊 Sysmon Log Parser with Threat Intelligence Enrichment

A detection-engineering project that parses Windows Sysmon logs, extracts security-relevant indicators, and enriches them with threat-intelligence sources.

The parser identifies suspicious processes, command-line activity, network connections, file changes, hashes, domains, and IP addresses. Detected activity is mapped to **MITRE ATT&CK techniques** and built into an automated timeline of the most suspicious activity for investigation and threat hunting.

**Key Areas:** Log Analysis, Windows Security, Sysmon, IOC Enrichment, Threat Hunting, Detection Engineering

**Tech Stack:** Python, Sysmon, VirusTotal, URLScan, ThreatFox, MITRE ATT&CK, JSON, Windows Event Logs

🔗 **Repository:** [View Sysmon Security Parser](https://github.com/RoshiniMlakshmana/sysmon-security-parser-and-log-analysis)
